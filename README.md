# 🛡️ Dilshan X-UI

**Advanced Xray Management Panel** — A worldclass premium dark-themed VPN server management panel built on top of X-SL/3x-ui.

## ✨ Features

- 🎨 **Premium Dark UI** — Deep space navy theme with teal/cyan accents
- 🔮 **Glassmorphism Design** — Modern frosted glass effects throughout
- ⚡ **Multi-Protocol** — VMESS, VLESS, Trojan, ShadowSocks, WireGuard
- 📊 **Real-time Dashboard** — CPU, RAM, Disk, Network monitoring
- 👥 **User Management** — Traffic limits, expiry dates, QR codes
- 🔐 **SSL Support** — Built-in certificate management
- 🌐 **Multi-Language** — English, Persian, Chinese, and more
- 📱 **Responsive** — Works on desktop and mobile

## 🚀 Quick Install

```bash
bash <(curl -Ls https://raw.githubusercontent.com/vishwa7502/dilshan-ui/main/install.sh)
```

## 📋 Management Commands

```bash
dilshan-x-ui              # Interactive menu
dilshan-x-ui start        # Start panel
dilshan-x-ui stop         # Stop panel
dilshan-x-ui restart      # Restart panel
dilshan-x-ui status       # Check status
dilshan-x-ui log          # View logs
dilshan-x-ui update       # Update to latest
dilshan-x-ui uninstall    # Remove panel
```
